# Add New Words — English Vocabulary to Anki

Turn a plain list of English words into ready-to-study Anki cards, each with a
B2-level example sentence, IPA, Brazilian Portuguese translation and an audio
clip generated by Google text-to-speech.

You add words to `words.txt`; the scripts do the rest:

```
words.txt  ->  anki_words.py  ->  anki_import.csv  ->  check_csv.py  ->  import_to_anki.py  ->  Anki
                (cards)            (card CSV)           (quality check)      (notes + audio)
```

---

## 1. Prerequisites

Install these once, before the first run.

| Requirement | Details |
| --- | --- |
| **Python 3** | `python --version` must print 3.x |
| **Anki** | Must be **open** every time you run the scripts |
| **AnkiConnect add-on** | In Anki: *Tools → Add-ons → Get Add-ons…*, code **2055492159**, then restart Anki |
| **Decks** | `English Vocabulary` and `B2 First` (subdecks included). The duplicate check only looks at these |
| **opencode** | The card writer. Check with `opencode --version` |
| **gTTS** | For audio: `python -m pip install gTTS` |
| **Internet** | Needed for dictionaries and Google text-to-speech |

If `python -m pip` is not available (Arch Linux, for example), install gTTS into
your user site-packages:

```bash
uv pip install --target "$(python -c 'import site; print(site.getusersitepackages())')" gTTS
```

Verify the install:

```bash
python -c "import gtts; print(gtts.__version__)"
```

## 2. Add the words

Open `words.txt` and put **one item per line**. Two formats are accepted:

```text
entreated
```

```text
*leapfrogs* the ability to attract top engineers
```

- A single word or expression: just write it.
- A sentence with the new word: wrap **only the target word** in `*stars*`. The
  rest of the line is context that tells the agent which meaning to use.
- Empty lines and repeated words (case-insensitive) are ignored.
- Spelling mistakes are corrected automatically (e.g. `acquaintence` → `acquaintance`).

---

## 3. Generate the cards

Run in the project folder:

```bash
python anki_words.py --no-dict
```

The script:

1. checks Anki for duplicates (only in the two configured decks);
2. skips words that already exist and lists them;
3. asks the AI to write the sentence, meaning, IPA and translation;
4. writes `anki_import.csv`.

Use another input file if you want:

```bash
python anki_words.py other.txt --no-dict
```

> **Note:** `--no-dict` is the normal mode here because the dictionary sources are
> currently unavailable. If they start working again, use
> `python anki_words.py --allow-unverified` instead.

---

## 4. Check the CSV before importing

```bash
python check_csv.py --fix --anki
```

- `--fix` applies only safe repairs (double bold, repeated `(informal)`, stray `*`)
  and saves the result as **`anki_import_fixed.csv`**.
- `--anki` also confirms the words are not already in your decks.

Read the output line by line:

```
Line   1 | unclasping | WARNING | the meaning contains ';': give only one meaning
2 cards checked: 0 error(s) on 0 line(s), 1 warning(s).
```

- **ERROR** — the card is broken; that line will be refused at import time.
- **WARNING** — the card is usable, but review it in Anki afterwards.

If Anki is closed, run the check without the Anki part:

```bash
python check_csv.py --fix
```

---

## 5. Import into Anki with audio

```bash
python import_to_anki.py anki_import_fixed.csv
```

This creates an MP3 of each Front sentence with Google TTS, adds
`[sound:file.mp3]` to the Front, and inserts the notes into **English Vocabulary**
(note type `Basic`) with the tags:

- `english`
- `import-YYYYMMDD` — one batch tag per day, e.g. `import-20261020`

Lines with an ERROR are skipped automatically; the good ones are still imported.

---

## 6. What happens to `words.txt`

After a successful import, the words that reached Anki (imported **or** already
present) are removed from `words.txt`. Only failed lines are kept, exactly as you
wrote them, so the next run retries them. See step 5 of `AGENTS.md`.

## Card format

Each CSV row is `Front;Back`:

```text
They <b>cling</b> to hope.;Meaning (cling, verb): hold tightly<br>Meaning (imperative form of the verb): cling!<br>Phonetic: /klɪŋ/<br>Tradução: agarrar-se, apegar-se, grudar
```

- **Front** — one natural B2 sentence, 6–10 words, target word in `<b>...</b>`.
- **Back** — one short meaning, part of speech, imperative line for verbs,
  `Phonetic: /IPA/`, and `Tradução:` in Brazilian Portuguese (1–3 options).

## Useful commands

| Command | What it does |
| --- | --- |
| `python anki_words.py --no-dict` | Make cards from `words.txt` |
| `python anki_words.py `*`file`*` --no-dict` | Make cards from another list |
| `python check_csv.py --fix --anki` | Test and safely fix the CSV |
| `python import_to_anki.py anki_import_fixed.csv` | Import notes with audio |
| `python import_to_anki.py --dry-run` | Show what would be imported, change nothing |
| `python import_to_anki.py --no-audio` | Import without audio |
| `python import_to_anki.py --audio-only` | Add audio to notes from today's batch |
| `python import_to_anki.py --audio-only --search "added:2"` | Add audio to notes from the last 2 days |

For `--audio-only`, close the Anki **Browser** window first.

---

## Manual import (only if needed)

In Anki: **File → Import**, choose the CSV, set the separator to **semicolon**,
and enable **Allow HTML in fields**.

---

## Troubleshooting

| Problem | Fix |
| --- | --- |
| `Cannot reach Anki` | Open Anki and confirm AnkiConnect is installed and enabled |
| `No module named gtts` | Run the gTTS install command above, then retry |
| A line was refused | Read the ERROR in `check_csv.py`; the card was not imported |
| `bulked up` not bold | The sentence used another form of the word; rewrite it in the same form |
| No audio on some cards | Google did not answer; rerun `python import_to_anki.py --audio-only` later |
| Words keep coming back | They failed to import, so they stay in `words.txt` by design |
| CSV looks quoted | A field contains `;` (e.g. two meanings); write a single meaning instead |
